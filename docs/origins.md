# 来源与实现分界

Mechanism Studio 从 Anatomy 的机制先行、同一模型驱动动作与读数、实际画面验收等思路起步，早期技能文本沿用并改写这些原则。来源与 MIT 通知保存在 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

当前运行时不调用 Anatomy 绘图库、套件或兄弟目录。公共查看器、姿态绑定、配音/资产模块、Blender 源模型与机构页面在此项目实现。独立仓库指构建、接口与维护边界独立，已有来源仍准确记录。

本项目实现原创锁芯、四缸、双轴涡扇与八自由度四足资产，稳定 ID 串联选中、运动、展开和课程；公共模块支持各机构自己的模型；中文豆包课程有文案与音频摘要核验；STEP 输入保留真实源和导入差异。

不主张首创三维、拆解、共享模型或线稿。独立价值来自机械数据入口、可靠接口、可复现资产与逐步验证的工程能力。

KFL08 为单独引入的第三方真实装配，作者、版本、CC BY 3.0 随源保留。原创资产的教学尺寸/结构简化明确说明，不冒充制造模型或商业产品。

Galileo 2 是第二个独立引入的真实 STEP 装配，来自 JaredC01 与 Galileo 2 contributors，固定提交与 GPL v3 全文保存在 `examples/shaft-bearing/source/`。轴、轴承支承件的功能名称依据上游装配手册；源文件字节不变。XCAF 导入、身份清单和查看页由本项目实现，派生显示资产保留上游署名与许可，不代表原作者参与本工具。
