- 状态模块独立测试 11/11 通过；根机械模型基线独立测试 9/9 通过。观察状态不改变机械判断，错误/空白钥匙不能转动，转动后撤钥匙与换钥匙归零，五个教程步骤原子切换，展开只锁定操作界面。
- 最终浏览器测试 18/18 通过，0 页面异常、0 控制台警告、0 资源错误。机器可读结果见 [browser-check.json](browser-check.json)。
- 实际 GLB 与清单、共享模型规格一致：1,035,044 字节、24 个唯一顶层部件、0 动画。实际场景 75,706 个三角形、46 次绘制调用；单位、转轴、弹子位置与弹簧缩放均按实际节点核验。
- 真实按钮、键盘输入、画布选择、五种镜头、剖切、展开、五个教程步骤与手机操作通过。转动时锁芯、钥匙、下弹子及尾部拨片一起转动，壳体、上弹子和弹簧保持原位。
- 静止、手机离屏及 reduced-motion 场景分别在取样期间记录 0 个新增动画帧回调、0 次新增 WebGL 绘制。展开后机械允许条件保持原值，操作界面禁用；教程能自动合拢。

## 复现与边界

先启动项目本地服务器，再在项目根目录运行：

```powershell
node --test prototype-3d/tests/state.test.mjs
node prototype-3d/tests/browser-check.mjs
```

浏览器脚本可通过 `MECHANISM_PLAYWRIGHT_PATH`、`MECHANISM_CHROME_PATH` 指定现有依赖，截图与缓存写入项目内。测试源见 [state.test.mjs](../tests/state.test.mjs) 与 [browser-check.mjs](../tests/browser-check.mjs)。

这是示意几何与离散状态教学原型，验收没有证明真实接触、摩擦、受力或工程公差。手机结果来自 Chrome 视口模拟，未覆盖真实移动硬件、其他浏览器、无 WebGL 环境及后台标签页生命周期；音频已验证加载和播放控制，未做主观音质听审。
