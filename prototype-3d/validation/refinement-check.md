# 白底黑线精修验证

历史精修日期：2026-10-11。用户确定白底黑线，要求更细腻的 Anatomy 风格，同时保留视角切换与拆解。这份记录来自目录拆分前的开发工作区；源码、最终资产与项目截图整理到当前独立项目后保留，不表示迁移时重新执行了下面的检查。

## 最终改动

壳体/锁芯圆周采样 64→128，弹子 48→72，弹簧路径 220→352 段、截面 8→12 边。补充端肩与浅环槽、五个弹簧座圈、槽头螺钉、弹子细环与座面；钥匙补充圆角握柄、实体孔、浅框/握槽及双面闭合纵向浅槽；底座增加闭合浅边槽、四个平齐固定窝和单块 5 PIN 浅刻铭牌。所有几何仍属于原有 24 个语义零件。

外轮廓/边界使用深灰黑，折角和内部结构使用浅灰线；同一个动态线段对象复用顶点与颜色缓冲。很浅的 Lambert 漫反射面表现圆弧，关闭金属高光、舞台渐变与投影。共面三角边不画，弹簧只画轮廓与边界。整体镜头略放大，放大后出界的标签隐藏。

最终 GLB：3,813,252 字节、170,357 三角；初始备份：1,035,044 字节、47,902 三角。规格哈希保持相同，顶层仍为 24 个零件/零动画，中性 TRS 和运动原点保持。原始资产及增量前版本在本机项目 `.tools/task-backups/refine-lock` 内保留，不随源码发布。

## 实际页面检查

通过 Codex 内置浏览器操作最终资产，使用 `line-light`：

| 操作 | 观察结果 |
|---|---|
| 初始未插入、匹配钥匙完全插入 | 整体画面保留钥匙握柄；5/5 接缝对齐，可转动 |
| 整体、纵向剖面、轴向、弹子近景、尾部 | 圆弧连续，弹簧/台阶可读；无宽面三角网格花纹 |
| 匹配钥匙 90°，尾部观察 | 锁芯、钥匙、下弹子和拨片一起转动；上弹子与弹簧留在壳体 |
| 关闭剖面 | 完整壳体遮住内部线条，端肩与顶盖紧固细节可见 |
| 90° 时展开 100% | 所有显示零件进入取景，机械控件暂停；合拢后恢复 100% 插入、90° 与可操作状态 |
| 错误钥匙、纵向剖面 | 3/5 对齐，只有第 2、4 组受阻轮廓为玫红，转动控件禁用 |
| 点击 5 PIN 铭牌 | 点选其所属的展示底座，显示作用说明 |
| 转动步骤播放并暂停 | 本地豆包 `turn.mp3` 正常播放，媒体 readyState=4，暂停按钮可用 |
| 390×844 窄屏模拟 | 页面内容宽/滚动宽均 375 CSS px，无横向溢出；整体画面完整 |

自由拖动/滚轮缩放在本轮前一版已验证；最终增量只有几何细节，运动与镜头控制接口没有变化。独立读图复核整体、近景、转动后拆解三张最终图，未发现阻断视觉问题。

## 范围与出处

以 [Anatomy 官方 craft 指南](https://github.com/wheresryan22/anatomy/blob/main/references/craft.md)为线稿工艺参考；当前独立项目不要求安装其原版套件。机械形态参考 [Schlage 锁芯维修手册的零件图](https://commercial.schlage.com/content/dam/allegion-us-2/web-files/schlage/technical-documents/Schlage_Everest_Full_Size_Cylinder_Service_Manual_108484.pdf)，只借用端肩、固定槽和腔口座等通用形态；没有采用品牌专用机构或工程尺寸。浅漫反射材质参考 [Three.js MeshLambertMaterial](https://threejs.org/docs/pages/MeshLambertMaterial.html)。

新增浅槽与细环不参与现有开锁规则，不表示槽型识别或特殊安全弹子行为。机构仍是示意尺寸的平面剪切线模型，没有新增接触、摩擦、力学或碰撞求解。原 Anatomy SVG 套件审计不适用于此 Blender/GLB 原型，未宣称通过该审计。窄屏为桌面模拟；未测真机帧率、耗电或所有任意视角。

精修时修改、便携工具、缓存、资产、备份与记录均留在当时获授权的本地工作区，没有安装全局 skill 或扩大权限。后续拆分后，新版可控产物限定在当前独立项目；本机运行时和备份不随源码发布。精修及目录整理均沿用已有豆包音频，没有因搬迁重新调用语音服务。
