# 四缸发动机：Mechanism Studio 的第二个完整实例

**Public checkout:** model, GLB, Blender builder, captions and voice-generation
code are included. Local `.blend` exports and provider-generated MP3s are
excluded from Git; the development notes below also describe those optional
files. See the [example catalog](../README.md) and [license policy](../../docs/licensing.md).

学习问题：四个活塞如何通过同一根曲轴接力工作；为什么同高的两个活塞可能处在不同冲程；怎样从不同视角辨认气门、连杆、曲拐和输出端。

这个实例按本项目已安装的 `.agents/skills/mechanism-studio/SKILL.md` 制作，重新建立发动机的几何资产与运动模块，交付可编辑 Blender 模型、GLB 显示资产、中文互动页面、五步教学文案及豆包语音。当前范围是机构教学展示，工程 CAD 装配与热力仿真仍需后续实现。

## 使用

在 Mechanism Studio 项目根安装网页依赖并启动：

```powershell
npm ci
npm run preview
```

打开 `http://127.0.0.1:4179/examples/inline-four/`。父工作区服务的同一实例位于 `/mechanism-studio/examples/inline-four/`，但本实例运行不依赖父目录或兄弟项目的代码。`?embed=1` 提供紧凑对比布局。

Three.js 使用项目根的锁定依赖和 `node_modules`，无需在锁芯目录另装依赖。公共查看器负责资产加载、稳定身份、OrbitControls、相机、点选、线稿与观察展开；本例保留四冲程公式、教学步骤与气门/连杆工作姿态。豆包生成与播放使用 [共享配音模块](../../shared/voice/README.md)。

- 播放或拖动曲轴角，观察 0–720° 的完整循环；手动 720° 保留显示端点。
- 切换整体剖视、曲轴端、侧面剖视、气门近景，或拖动自由旋转。
- 点击零件查看中文作用；选择 1–4 缸，读数跟随所选缸。
- 打开或关闭预制教学剖面；拆解会暂停机械播放，展示位移不改变原装配读数。复装后可以继续。
- 五个教学步骤均暂停在明确角度。手动机械输入会退出当前解说。
- 默认开启“过程示意”：蓝色进气/混合气、金色短进气道喷射、活塞上行时缩小的气体空间、上止点火花、淡橙燃烧前沿与排气流出。关闭它可以回到纯机械线稿。
- 豆包音频由本地生成端读用户授权的凭据；网页只读本地音频。尚未生成时明确显示状态，不用其它 TTS 代替。

本轮五步豆包音频已实际生成，`voice/audio-manifest.json` 记录服务、音色、文案摘要和各文件校验值；没有把凭据复制入本目录。

## 机械模型与共同对比基准

| 项目 | 教学规格 |
|---|---|
| 缸径 / 行程 / 连杆中心距 | 82 / 90 / 150 mm |
| 四个缸沿机体 X 轴位置 | −156、−52、52、156 mm |
| 发火顺序 | 1 → 3 → 4 → 2，每 180° 一次 |
| 1–4 缸发火相位偏置 | 0、540、180、360° |
| 单缸循环 | 做功 0–180°、排气 180–360°、进气 360–540°、压缩 540–720° |
| 气门升程 | 对应完整理想行程内 9 mm 正弦展示升程，端点为零 |
| 凸轮轴 | 曲轴角的一半；轮廓从同一气门升程模型采样 |

活塞销中心高度由 `r*cos(theta) + sqrt(l*l − r*r*sin(theta)^2)` 得到，其中 `r=45 mm`、`l=150 mm`。曲轴销绕轴运动，连杆从曲轴销指向活塞销；运动姿态、阶段说明、升程与数值均来自 `model.mjs`。

原版 Anatomy 对照实例采用相同尺寸、相位、发火顺序和 9 mm 正弦展示升程，便于比较二维机制表达与三维空间观察。两版都没有把阶段示意写成燃烧或动力学求解。

机械模型仍只在做功起点的上止点瞬间判定点火；显示层把火花延长为其后 14° 的可见教学窗口。没有实际点火提前角、气门重叠、工程压缩比、气体压力、功率、动态摩擦、润滑或冷却模拟。气门弹簧是静态辨识细节，不求解弹性或动态压缩。凸轮轮廓是理想配气显示资产，没有接触、配合、磨损或运动学约束求解。

## 同一曲轴驱动的过程示意

`process.mjs` 从现有 `engineState(angle)` 派生过程，不改 `model.mjs`，不添加第二个时钟。四缸继续使用原发火相位；播放、暂停、拖动到同一个曲轴角时，流向、喷射、火花、燃烧前沿和气体空间完全一致。暂停会冻结当前过程，也可以停在火花或燃烧可见的相位，方便讲解。

- 进气流入、进气道喷射与排气流出强度分别来自现有进/排气门升程；阀门关闭时对应流动为零。金色短路径汇合到蓝色进气路径，表达预混进气/进气道喷射的教学简化，不表示柴油压缩末喷油、缸内直喷、真实喷油量或油滴轨迹。
- 展示空间的下边界来自同一活塞销高度加资产活塞顶偏移，上边界固定为示意缸顶；压缩时空间随原活塞曲线缩小，做功时扩大。它不用于计算真实压缩比、密度、温度或压力。
- 火花在各缸做功相位 0–14° 可见；小分叉星光位于预制剖面的前半腔内，避免被进气阀盘遮住，仍受金属深度遮挡。它是可见的点火教学标记，不代表源火花塞电极的精确位置。橙色前沿在做功前段从缸顶向下推进并淡出。这两个窗口都是观察设定，没有实际燃烧标定、火焰传播方程或热释放求解。
- `effects.mjs` 使用共享 `shared/animation/effects.mjs` 的流向和事件标记；没有自主动画循环、随机发火或 wall-clock 事件。效果不会进入零件身份、拾取网格或模型取景边界。
- 关闭教学剖面或展开任何程度时，过程层隐藏，避免气流和火花漂在分离部件之间。复装后在相同机械相位恢复；切换过程开关不改变机械状态、教学文案或正在播放的豆包音频。

建议先暂停在 **90°**，比较四缸同时出现的做功、排气、压缩与进气/喷射；再停在 **5°** 看一缸火花，拖过 14° 看窗口结束。默认白底黑线保留，颜色只用于少量过程语义。这些是因果过程的教学可视化，不是燃烧压力、流量、喷雾或 CFD 仿真。本次保留原资产和五段豆包课程，没有重新生成或调用配音。

## 资产契约与可编辑源

- `assets/inline-four.blend`：实际执行 Blender 4.5.14 LTS 建模生成的可编辑源。
- `assets/inline-four.glb`：46 个逻辑零件、423 个网格、97,224 个三角形，约 3.27 MB。
- `assets/scene-contract.json`：稳定 `part_id`、中文术语、装配父节点、rest、轴心、运动所有者及拆解向量。
- `spec.json`：由 JS 模型导出的尺寸、初始姿态和采样凸轮轮廓；不是另一套手写运动公式。
- `blender/build-engine.py` 与 `blender/export-spec.mjs`：可复现的参数化教学建模源码。
- `assets/build-report.json`：本轮实际执行版本、SHA-256、计数和已完成导出检查。

Blender 几何使用米，机体约定为毫米、X 沿缸列、Z 向上；glTF 约定为米、Y 向上，转换 `0.001*[x,z,-y]`。GLB 保留初始 rest。运动节点由模型写入一次绝对 engine-local 姿态，观察层只加入拆解位移；没有动画片段与程序同时写入一个通道。

本轮没有可用的通用 Blender MCP 连接，已有 MCP 仍限制为原有锁芯操作。本例使用本项目已有便携 Blender 和获授权的本地建模脚本，没有扩展 MCP、修改全局配置或访问兄弟项目。构建缓存、临时文件与用户资源目录均位于本实例 `.cache/`，不公开上传。

重新构建时，在项目根运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File examples/inline-four/blender/build-engine.ps1
node --test examples/inline-four/tests/model.test.mjs examples/inline-four/tests/asset.test.mjs
node --test examples/inline-four/tests/process.test.mjs examples/inline-four/tests/effects.test.mjs
```

Blender 可执行文件需在项目已有 `.tools/blender-4.5.14-windows-x64/blender.exe`；脚本不自动下载安装软件。模型和资产测试共 14 项实际通过，覆盖全 720° 的杆长/曲柄半径、相位、配气、半速读数、输入边界、观察不改变机械状态，以及 GLB 身份、真实层级、坐标单位、初始姿态、采样轮廓和教学 ID。

过程与效果另有 10 项测试通过：原发火顺序与有限窗口、气门关闭时的流动门控、真实活塞曲线对应体积、做功专属前沿、暂停/定位可重复、观察隐藏不改相位、火花分叉在开放腔内的边界、外部喷射段及其与蓝流的汇合，以及实际 GLB 的身份/拾取/取景边界隔离。原 14 项资产/模型检查保持通过。

视觉验证检查实际网页、整体与气门近景、曲轴端和侧面、拆解复装、720° 端点、零件点选/自由旋转、减弱动画变化暂停和 390 px 页面。曲轴端教学剖面还隐藏两块预制端壁，避免遮住目标连杆；这不是任意剖切。记录见本地 `output/browser-check.json` 及截图，output 为本机验证记录，不属于公开源码清单。这些检查不证明完整三维网格在所有角度均无干涉，也不构成加工尺寸或工程安全验证。

## 原理来源与范围

[NASA Glenn：四冲程发动机的工作过程](https://www.grc.nasa.gov/www/k-12/airplane/engopt.html) 支持四冲程、曲轴转两圈而凸轮轴转一圈的基础原理。本例是自建的直列四缸教学示意，并未复刻 NASA 页面所述 Wright 发动机，也没有沿用其历史机型尺寸。

显示层使用根依赖 Three.js 与 [共享查看器](../../shared/viewer/README.md)，特征边缘的唯一实现位于 `shared/viewer/line-art.mjs`；锁芯旧路径仅作兼容转发。项目保留第三方许可。没有导入原生 CAD / STEP / B-rep 源；未来工程 CAD 方向需另验证源几何、实例身份、配合、剖切和精确测量。
