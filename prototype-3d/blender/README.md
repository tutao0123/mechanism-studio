# Blender 锁芯资产

这里的 `build-lock.py` 在便携 Blender 4.5.14 LTS 中生成真实 `.blend`、`.glb`、预览图和资产清单。`prototype-3d/spec.json` 来自项目已有原理模型，尺寸为教学示意，按 `metersPerUnit=0.001` 换算为米。资产没有刚体、driver 或机构动画。

在 Mechanism Studio 项目根目录，从 PowerShell 执行项目内脚本重建：

```powershell
& './prototype-3d/blender/build-lock.ps1'
```

开发机器的 Blender 位于项目 `.tools/blender-4.5.14-windows-x64`。脚本从自身位置定位项目，将用户资源、config、scripts、datafiles、缓存和临时目录设为项目 `.tools` 子目录；不安装用户级或全局软件，不修改系统设置。Blender 运行环境不随源码发布；新使用者需先按脚本要求准备项目内 Blender，已有 GLB 的网页预览不需要运行 Blender。

本页的首次生成、精修规模与检查描述来自目录拆分前的开发记录；模型和源码保留在当前项目，不表示此次迁移重新生成了资产。项目受限 MCP 另见 [源码说明](../../tools/blender-mcp/README.md)，它不是该模型最初生成的方式。

- [官方 4.5 LTS 发布说明](https://www.blender.org/releases/4-5/)
- [官方便携下载路由](https://mirror.blender.org/release/Blender4.5/blender-4.5.14-windows-x64.zip)
- [官方校验清单](https://mirror.blender.org/release/Blender4.5/blender-4.5.14.sha256)

网页资产接口：

- 所有 24 个 mesh 为顶层节点，节点 `extras.part_id` 与名称一致且唯一。前后壳体是 `shell-back`、`shell-front`，前后锁芯是 `plug-back`、`plug-front`。前半在 Blender `y<0`，默认隐藏前半以展示剖面。
- `lower-1..5`、`driver-1..5`、`spring-1..5` 的中性 rest 是 `(pinX,0,0)`。下弹子和上弹子网格底部局部 `z=0`，网页按模型设置底部高度。
- 下弹子长度使用原理模型规格；底部为尖锥教学接触面。上弹子长度为 36 示意毫米。
- 弹簧 Blender 本体局部 `z=0..1` **米**，导出后是 glTF 本体 `y=0..1` 米。网页将 GLB 节点 `scale.y` 设为所需高度的米数，并将 `position.y` 设为上弹子顶部。参考高度 18mm 时线材截面近似圆形；其他高度是教学拉伸，不能当作真实弹簧受力解。
- `key-correct`、`key-wrong`、`key-blank`、`plug-back/front`、`cam` 的 Blender 原点为 `(0,0,0.036)m`；钥匙和锁芯轴方向为 X。网页围绕自己的同轴 wrappers 转动。
- 钥匙刃顶使用 model 的完整折线：`z=14+height`，下底 `z=8`，刃厚 4.8 示意毫米；网格无接触边倒角。钥匙位移与轮廓采样都由同一原理模型控制。
- Blender 导出自动转换到 glTF `+Y up`：`[x,y,z]→[x,z,-y]`；轴心在 glTF 为 `(0,0.036,0)m`。所有准确 rest、实际 GLB TRS、本体 bounds 以 `assets/asset-manifest.json` 为准。

GLB 为中性 rest，供网页驱动；`.blend` 保存匹配钥匙已插入、转角为零的装配展示状态。两者姿态差异已写入清单。GLB 同时携带三把钥匙，网页应按 `defaultHiddenPartIds` 和当前选择管理可见性。

生成后脚本检查 GLB 二进制头、24 个唯一 ID、顶层结构、实际原点和零动画，再生成清单。Cycles 预览图经过人工查看。模型只展示共用 JS 模型的平面剪切线规则，不证明真实圆柱接触、受力或无碰撞；页面需要保留“教学尺寸、非物理仿真”的说明。

## 白底黑线用精细资产

2026-10-11 的精细版本保留上述 24 个语义零件及全部运动接口。壳体与锁芯的圆周采样从 64 增到 128，下弹子与上弹子的圆周采样从 48 增到 72；弹簧连续路径从 220 段增到 352 段，线材截面从 8 边增到 12 边。细节来自实际几何，供网页根据视角绘制可见轮廓与结构线，未给模型加入三角网格线或额外机构动画。

- 壳体：两端轴承肩、两条浅环槽、五处弹簧腔口座圈、八个有真实槽口的顶盖固定螺钉。座圈和螺钉底部埋入壳体，再先做实体并集、后做前后剖切；避免相交网格直接合并导致剖切失效。
- 锁芯：原直径范围内的两端倒角肩与浅环槽。钥匙通道、弹子孔、旋转轴与模型规定的尺寸保留。
- 弹子：细小卸荷环与顶部座面；底部高度及每根弹子总长度保留。弹簧只细化连续线材，不把会随高度缩放而变形的刚性端帽接到弹簧上。
- 钥匙：圆角钥匙柄、实体穿孔、两面浅边框与每面三道握持浅槽；刃片双面各有一条两端闭合圆角的浅纵向导槽。纵槽限定在 `x=12..148mm, z=10.475..11.525mm`，高于原下底 `z=8mm`、低于全部接触折线 `z>=14mm`，三把钥匙刃口的完整接触折线及两侧厚度顶点保留。
- 底座：支架固定螺钉增加真实槽口与垫圈；板面只有一道沿板轮廓的闭合浅环槽，四个平齐槽头固定窝对准原脚轴 `x=0/154mm, y=±35mm`。仅有一个 `20×8mm` 的 `5 PIN` 浅刻铭牌，凸起 `0.22mm`。均归入原有静态底座，不添加尺刻线或虚构尺寸。

清单 `geometricFinesse.semanticDetails` 记录 74 个逻辑细节实例，并非 74 个机械零件。其中钥匙的 33 项是三把钥匙各自重复的 11 项，网页同一时刻只显示一把钥匙；剩余 41 项归属共用锁体与底座。曲面采样和弹簧线材细化另行记录，不计入该数。

精修记录中的最终 GLB 为 3,813,252 字节、170,357 个三角形，低于当时 180,000 三角预算；原备份为 1,035,044 字节、47,902 个三角形。原文件和构建日志保留在本机项目 `.tools/task-backups/refine-lock`，最后一轮前的版本及日志另存于其中 `incremental` 子目录；这些本机备份不随源码发布。脚本新增实际半壳/半锁芯边界检查，生成清单记录原点、采样、三角数、图元数与字节数。可从当前根目录运行以下检查，验证导出的二进制几何，而非只核对清单声明：

```powershell
node --test 'prototype-3d/tests/asset-contract.test.mjs'
```

该检查涵盖 24 个顶层 ID 与中性 TRS、规格哈希、实际位置缓冲范围、弹子底部与长度、半壳剖切平面、弹簧规范高度，以及三把钥匙原接触折线的双侧顶点。`.blend` 与预览仍是匹配钥匙完整插入、转角为零、五组接缝对齐的装配姿态；GLB 仍是网页接管的中性姿态。
