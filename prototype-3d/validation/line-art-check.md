# 黑白线稿验证

此记录对应首次黑白主题实现。2026-10-11 精修已将无光照面更新为浅 Lambert 漫反射面，并将外轮廓与结构线分为深浅两层；当前验证见 [refinement-check.md](refinement-check.md)。以下保留当时的实现与检查结果。

本次将白底黑线与黑底白线接入同一 3D 原型。主题 ID 为 `line-light`、`line-dark`；无有效指定或保存主题时默认 `line-light`。原来的十套方案仍可切换。

## 表现实现

- 不透明的无光照轻灰面提供深度遮挡；可见轮廓、边界及 25° 以上世界空间折角使用线段表达，省略共面三角划分。
- 视角方向变换到每个零件的局部空间，适用于转动父层及弹簧非均匀缩放。邻面折角缓存根据归一化法线度量刷新，单纯转动不重算。
- 弹簧标记 `lineArtSmooth=true`，只画轮廓和边界，避免低分段管面折线干扰线圈阅读。
- 预分配动态顶点缓冲，更新时复用；实体 bounds 与 raycast 排除子线段。黑白模式关闭投影、渐变和金属反光；标准 WebGL 线宽为 1 像素。
- 受阻弹子的轮廓优先于点选轮廓颜色。点选只增加轻灰填面提示，不清除受阻提示。

## 实际浏览器检查

使用 Codex 内置浏览器，通过页面控件操作与截图核对：

| 场景 | 结果 |
|---|---|
| 白/黑同姿态比较：匹配钥匙 100%、转角 0、整体剖面 | 连续轮廓、圆柱与线圈可读，无三角网格花纹 |
| 转角 90°、轴向与尾部 | 可见轮廓随零件与相机更新 |
| 展开 100%、尾部观察 | 所有显示零件进入取景；机械控件暂停，合拢后恢复 |
| 关闭剖面 | 内部弹子及后方被遮挡线条消失 |
| 错误钥匙、纵向剖面 | 第 2、4 组轮廓有玫红提示，3/5 对齐且转动禁用 |
| 点选模型中央 | 可选中锁壳并显示零件作用，线段不拦截选择 |
| 90° 时播放豆包解说，再切黑→白 | 保留 100% 插入、90°、本地 turn.mp3 且仍播放 |
| 线稿→VS Code 深色→线稿 | 原有材质恢复；切回线稿时无残留光照或投影 |
| 弹子近景 | 弹簧线圈与五组接缝可读，近景按设计裁去部分外壳 |
| 390×844 窄屏 | 两套主题均可读，无横向溢出；整体观察自动按实体 bounds 取景 |

窄屏初次检查发现整体画面裁到左侧底座，已修正为窄舞台整体镜头自动适配。切换外观与点选不触发重新取景；自由转动、缩放仍保留。

## 检查边界

原理模型与控制器的 20 项测试通过。线稿的纯几何性质由 `tests/line-art.test.mjs` 检查：立方体无对角线、圆柱动态轮廓、变换与平滑曲面、样式/缓冲复用/释放。

截图验证覆盖教学姿态与预设镜头，没有穷举任意自由镜头。当前线稿仅支持此原型的正交相机、静态网格及程序父层变换，不支持蒙皮或实例化网格。手机尺寸是桌面浏览器模拟，未作为真机帧率或耗电测试。
