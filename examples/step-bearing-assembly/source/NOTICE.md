The unchanged `cad_files/assembly.step` is available under the upstream
[Apache License 2.0](LICENSE.txt). It is fetched from its pinned URL and verified
by SHA-256 instead of duplicated in Git. Retained attribution and provenance
apply to the separately generated display assets as well.

Mechanism Studio changes: import through OCCT XCAF, retain source product and
usage identities, tessellate display surfaces, normalize the coordinate system,
and add an inspection interface. No geometry is substituted, and no mates,
manufacturing precision or physical behavior are inferred from that conversion.

The upstream project credits SO-ARM100, LeRobot and MuJoCo Menagerie for the
related follower-arm and teleoperation ecosystem. This example imports only the
leader arm's own STEP assembly, not those software or simulation packages.

No upstream `NOTICE` file exists at the pinned repository root; this file records
our source attribution and modification description.
